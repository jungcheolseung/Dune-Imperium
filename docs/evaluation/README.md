# 평가 기록 색인

측정·실험 기록이다. 문서마다 그때의 엔진(codec·관측 버전)에서 잰 값이라, 규칙이 바뀐 뒤의 엔진과 수치를 바로
비교하지 않는다([개발 인수인계](../development-handoff.md) "알아 둘 것"의 측정 비교). 2026-10-12에 만들었다. 새 기록을
더하면 이 표에도 한 줄을 더하고, 앞 기록을 대체하면 그 줄의 상태를 고친다.
