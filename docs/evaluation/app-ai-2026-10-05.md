## 1. 무엇을 쟀나

`app_ai`는 Steam 앱(4.1.2.1808)의 컴퓨터 상대를 그대로 옮긴 agent다. 난이도는 앱과 같이 상수표만 다르다(`app_ai` = Hard,
`app_ai_medium`, `app_ai_easy`). 아래는 모두 `--rotate-leaders`(시드마다 지도자 4명 무작위)이고 CHOAM 유무(`--ruleset both`)를 같이
돈다. 비교는 `scripts/ab/paired.py`(시드 묶음 부트스트랩)로 했다. 스크립트는 `ab-runs/app-ai/run_ab.sh`(git 무시), 출력은
같은 폴더의 `*.jsonl`·`*.md`.

```bash
uv run dune-imperium-tournament --agents app_ai,heuristic,app_ai,heuristic --games 500 --ruleset both \
    --rotate-leaders --workers 8 --matches ab-runs/app-ai/app_vs_heur_s0.jsonl
uv run python scripts/ab/paired.py ab-runs/app-ai/app_vs_heur_s0.jsonl --a app_ai --b heuristic
```

## 3. 해석

- **앱 AI(Hard)는 우리 heuristic보다 훨씬 강하다.** 2:2에서 heuristic 좌석은 4% 안팎밖에 못 이긴다. 앱의 설계(국면·보유량에 따른
  자원 가치, 최소 가치 미만 카드는 사지 않기, Swordmaster·High Council 우선, "필요한 만큼만" 병력)가 우리 행동 종류별 고정 점수보다
  훨씬 낫다는 뜻이다.
- **난이도 순서가 앱과 같다**: Hard > Medium > Easy. Easy는 Hard의 판단 방향을 뒤집은 상수표라 차이가 크다(+47pp).
- **우리 학습 망은 greedy로는 앱 Hard보다 약하다**(2:2에서 13.5%). 다만 이 체크포인트는 L1(턴 종료 버튼)·L2(자동 처리 → 결정 창)와
  그 뒤 규칙 재판정들 **이전** 규칙으로 학습했고 재적응(L3)을 하지 않았다. 지금 규칙에서 손해를 보는 몫이 섞여 있다.
- **search는 앱 Hard보다 강하다.** 앱 Hard 셋을 상대로 혼자 좌석당 48.5%(기대값 25%), 평균 순위 1.89를 낸다. 결정당 0.29초라 사람과
  두기에도 쓸 만한 속도다.
- 강도 순서: search ≫ app_ai Hard > app_ai Medium > 학습 망 greedy ≈ app_ai Easy(직접 비교 안 함) ≫ heuristic.

## 4. 한계

- app_ai의 앱 충실도는 실제 앱을 돌려 대조한 것이 아니라, 역어셈블 사양에 대한 코드 대조(단계마다 독립 검증)로만 보장된다.
  앱 엔진과 우리 엔진의 규칙 차이(`../app-ai-plan.md` 6절)도 있다.
- 동점은 앱처럼 무작위로 깨지만 agent의 시드 RNG를 쓴다(앱은 시계 시드).
- 학습 망 칸은 위 3절의 규칙 변경 문제가 있다. 재적응 뒤 다시 잰다.
