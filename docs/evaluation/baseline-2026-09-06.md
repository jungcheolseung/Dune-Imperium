## 5. 첫 학습 체크포인트(M10 슬라이스 1, commit `01a6a18`+`d9f11a5`) vs random / heuristic

이 Mac(Apple M4, CPU)에서 아래 명령으로 약 6분 학습한 체크포인트(pure self-play 30 iteration × 32판 = 960판, REINFORCE + value baseline, hidden 512×512)를 greedy(`checkpoint:<경로>`)로 대회에 넣었다. 학습은 seed로 재현되지만 체크포인트 파일(약 14MB)은 저장소에 넣지 않는다.

```bash
uv run dune-imperium-train --out <dir> --iterations 30 --games-per-iteration 32 --eval-every 10 --eval-games 12 --eval-opponent random --seed 2
uv run dune-imperium-tournament --agents checkpoint:<dir>/latest.pt,random,random,random --games 25 --ruleset base --rotate-leaders --workers 4
uv run dune-imperium-tournament --agents checkpoint:<dir>/latest.pt,heuristic,heuristic,heuristic --games 25 --ruleset base --rotate-leaders --workers 4
```

| 상대(3좌석) | 판수 | checkpoint 승률 | 평균 순위 | 평균 VP | VP margin | ms/decision |
|---|---:|---:|---:|---:|---:|---:|
| random | 100 | 100.0% | 1.00 | 10.98 | +7.53 | 0.59 |
| heuristic | 100 | 56.0% | 1.80 | 8.77 | +2.41 | 0.59 |

학습 곡선(training.jsonl): 좌석별 승률은 pure self-play라 항상 25%이고, entropy가 1.22 → 0.84로 내려가며 정책이 뾰족해졌다. value head의 explained variance는 0.1~0.2에 머문다. 첫 smoke의 교훈: heuristic 3명을 상대로 시작하면(`--opponent heuristic`) 초기 정책이 한 판도 못 이겨 모든 보상이 −1/3이 되고 advantage가 0이라 20 iteration 동안 아무것도 배우지 못했다(승률 0%). pure self-play는 매 판 승자가 있어 신호가 생긴다.

## 6. 두 번째 체크포인트(100 iteration × 64판, 병렬 수집) — champion 비교

commit `3a028fe`(step penalty 0.0005, 게임당 4,000 결정 상한, minibatch 값 계산) 시점의 코드로 8 worker 병렬 수집을 써서 약 14분(수집 615초 + 갱신 219초) 학습한 체크포인트다. 6,400판 self-play. sampling 순환 방지(`cf24f35`)는 이 실행이 시작된 뒤에 들어갔으므로 여기에는 적용되지 않았다.

```bash
uv run dune-imperium-train --out <dir4> --iterations 100 --games-per-iteration 64 --workers 8 --eval-every 25 --eval-games 12 --eval-opponent heuristic --seed 3
uv run dune-imperium-tournament --agents checkpoint:<dir4>/latest.pt,heuristic,heuristic,heuristic --games 25 --ruleset base --rotate-leaders --workers 4
uv run dune-imperium-tournament --agents checkpoint:<dir4>/latest.pt,checkpoint:<dir2>/latest.pt,checkpoint:<dir2>/latest.pt,checkpoint:<dir2>/latest.pt --games 25 --ruleset base --rotate-leaders --workers 4
uv run dune-imperium-tournament --agents checkpoint:<dir4>/latest.pt,rollout,rollout,rollout --games 12 --ruleset base --rotate-leaders --workers 8
```

| 상대(3좌석) | 판수 | 새 체크포인트 승률 | 평균 순위 | VP margin |
|---|---:|---:|---:|---:|
| heuristic | 100 | 89.0% | 1.14 | +5.05 |
| 5절의 6분 체크포인트 | 100 | 61.0% | 1.65 | +2.61 |
| rollout | 48 | 66.7% | 1.46 | +3.90 |

루프 안 평가(heuristic 3명, 12판): 25 iteration 73%, 50 iteration 77%, 75 iteration 75%, 100 iteration 96%. 게임당 결정 수는 700~930 사이에서 흔들렸고(penalty 전 실행은 41 iteration에 1,793까지 폭증), entropy는 1.2 → 0.9 부근.

서열(2026-09-06 밤): random < heuristic < rollout < 6분 체크포인트 < 14분 체크포인트. 다음 champion은 14분 체크포인트다.

## 7. 비교 실험(부정 결과): sampling에도 순환 방지를 적용한 제로부터 재학습

6절과 같은 seed·설정으로, 수집(sampling) 정책에도 `_CycleGuard`(같은 라운드의 동일 관측에서 이미 고른 행동을 가림)를 적용한 코드(`cf24f35`)로 처음부터 다시 학습했다. 25 iteration에서 중단.

| iteration | 6절 실행 결정/게임 · entropy | 순환 방지 실행 결정/게임 · entropy |
|---:|---:|---:|
| 5 | 651 · 1.19 | 683 · 1.18 |
| 10 | 722 · 1.11 | 741 · 1.05 |
| 15 | 747 · 1.08 | 848 · 0.91 |
| 20 | 927 · 1.07 | 980 · 0.98 |
| 25 | 768 · 1.02 | 1,301 · 0.20 |

순환 방지가 sampling 분포를 바꾸는데 learner는 그 보정을 하지 않으므로(off-policy 데이터를 on-policy로 학습), 정책이 급격히 뾰족해지고(entropy 0.20) 가려진 행동 대신 다른 되돌리기 변형(deploy 1 → withdraw → deploy 2 → …)으로 반복이 오히려 늘었다. 결론: 순환 방지는 greedy(평가) 전용으로 두고 sampling은 가리지 않는다(`revert`). 반복 비용은 step penalty와 게임당 결정 상한으로만 다룬다.

## 읽는 법

- heuristic은 random 세 명을 상대로 95% 승률, 평균 순위 1.06, VP margin +5.7이다. 이후 rollout/search baseline과 학습 모델은 이 행렬에서 heuristic보다 유의미하게 높아야 한다.
- heuristic 미러의 좌석별 승률은 22.8~26.8%, first player 승률 25.0%로 좌석·선공 편향이 보이지 않는다. Leader별로는 Gurney Halleck(38.3%)이 강하고 Staban Tuek(17.2%)이 약한데, 이는 heuristic의 행동 점수가 Leader 능력을 고르게 활용하지 못한다는 뜻이지 Leader 밸런스의 근거는 아니다.
- rollout은 heuristic 세 명을 상대로 48% 승률(무작위 기대치 25%), 평균 순위 1.90, VP margin +1.5로 heuristic보다 유의미하게 강하다. 좌석별 40~56%로 좌석 편향은 없다. 결정당 약 25ms(8 worker 병렬 시 45ms)라 한 판에 약 4초가 들고, 100판 대회는 8 worker로 약 2분이다.
- 6분 학습한 첫 체크포인트가 heuristic 3명 상대 56%로 rollout(48%)을 이미 넘었고, 14분 학습한 두 번째 체크포인트는 heuristic 상대 89%, 첫 체크포인트 상대 61%, rollout 상대 67%다(6절). 이후 학습 실행은 같은 대회로 재고 직전 champion과 직접 대전한다.
- 불법 행동은 모든 실행에서 0이다. 결정 시간은 heuristic 약 0.005ms, random 약 0.001ms로 러너 오버헤드가 지배적이다.
