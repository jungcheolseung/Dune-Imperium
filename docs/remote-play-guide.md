# 멀티플레이 안내

호스트 한 명이 서버를 실행하고, 플레이어는 그 서버의 방 링크로 접속한다. 역할에 맞는 가이드를 선택하면 된다.

| 역할 | 읽을 문서 | 안내 내용 |
|---|---|---|
| 서버를 설치·실행하고 방을 관리하는 호스트 | [서버 호스트용 가이드](remote-play-host-guide.md) | 환경 준비, 서버 실행, LAN·Tailscale 설정, 방 생성과 공유, 저장·복구, 서버 문제 해결 |
| 호스트에게 받은 방 링크로 접속하는 플레이어 | [플레이어용 접속 가이드](remote-play-player-guide.md) | 준비 사항, 첫 접속, 플레이어 선택, 재접속, 기기 변경, 접속 문제 해결 |

플레이어는 게임 저장소나 Python을 설치할 필요가 없다. 같은 Wi-Fi·유선망에서는 브라우저로 접속하고, 다른 장소에서는 Tailscale을 설치해 호스트의 머신 공유 초대를 수락한다.

호스트도 플레이에 참여한다면 서버 준비를 마친 뒤 자기 플레이어를 선택해 참여한다. 참가자에게는 **플레이어용 접속 가이드**와 실제 **방 링크**를 보내고, Tailscale을 처음 연결하는 사람에게는 **머신 공유 초대 링크**도 함께 보낸다.

구현 구조와 설계 근거는 [멀티플레이 설계](multiplayer-design.md)에 있다. 문서 확인일: **2026-10-05**.
