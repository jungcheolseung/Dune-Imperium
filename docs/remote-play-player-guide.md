# 멀티플레이 플레이어용 접속 가이드

호스트가 만든 방에 접속해서 플레이하는 사람을 위한 문서다. 준비 사항, 첫 접속, 좌석 선택, 재접속과 접속 문제 해결을 안내한다. 서버를 직접 실행하는 사람은 [서버 호스트용 가이드](remote-play-host-guide.md)를 참고한다.

문서 확인일: **2026-10-05**.

## 1. 준비할 것

| 준비할 것 | 내용 |
|---|---|
| PC 또는 노트북 | 화면이 넓은 PC 기준으로 안내하며, 모바일만으로 한 판을 진행하는 환경은 검증하지 않았다 |
| 브라우저 | Chrome, Edge, Safari 등의 최신 데스크톱 브라우저; 쿠키 사용 허용 |
| 방 링크 | 호스트에게 받은 `http://<호스트 주소>:8000/#game=<게임 ID>` 형태의 링크 |
| Tailscale | 다른 장소에서 접속할 때 설치·로그인. 같은 Wi-Fi·유선망으로 접속하면 필요 없음 |
| 머신 공유 초대 링크 | Tailscale로 처음 접속할 때 호스트에게 받는 초대 |

게임 저장소, Git, Python, uv, AI 모델, 카드·보드 이미지 파일은 참가자 PC에 설치할 필요가 없다. 게임 설정과 저장은 호스트가 맡는다.

## 2. 처음 접속하기

### 같은 Wi-Fi·유선 네트워크에서 접속

1. 호스트와 같은 Wi-Fi 또는 유선 네트워크에 연결한다. 게스트 Wi-Fi에서는 기기 간 접속이 막혀 있을 수 있으므로 일반 네트워크를 사용한다.
2. 호스트가 보낸 **방 링크 전체**를 PC 브라우저에서 연다. 주소 뒤의 `/#game=...`까지 포함해야 한다.
3. 이름을 입력하고 자신이 사용할 빈 사람 좌석의 **앉기**를 누른다. 접속이 끝나면 자기 좌석 화면이 열린다.

### 다른 장소에서 Tailscale로 접속

1. [Tailscale 다운로드](https://tailscale.com/download)에서 자신의 OS용 앱을 설치한다.
2. 자신의 계정으로 로그인하고 Tailscale 연결을 켠다.
3. 호스트가 보낸 **머신 공유 초대 링크**를 열어 로그인하고 수락한다. 처음 한 번만 하면 된다. 수락 뒤 자신의 Tailscale 기기 목록에서 호스트 PC가 보이는지 확인한다.
4. 호스트가 보낸 **방 링크 전체**를 PC 브라우저에서 연다.
5. 이름을 입력하고 빈 사람 좌석의 **앉기**를 누른다. 게임 중에는 Tailscale 연결을 유지한다.

회사 관리 계정 등에서 초대 수락이 막히면 개인 Tailscale 네트워크의 계정을 사용하거나 관리자에게 확인한다. 공유 수락에는 자신의 네트워크에서 Owner·Admin·IT admin 권한이 필요하다. ([Tailscale 공식 머신 공유 안내](https://tailscale.com/docs/features/sharing))

**머신 공유 초대 링크**는 호스트 PC에 연결하도록 허용하고, **방 링크**는 실제 게임방으로 들어가게 한다. 두 링크의 용도가 다르므로 처음 접속할 때는 초대를 먼저 수락한 뒤 방 링크를 연다.

공유받은 호스트 PC가 다른 `100.x` 주소로 보일 수 있다. 방 링크가 열리지 않으면 자신의 Tailscale 기기 목록에서 호스트 주소를 확인하고 링크의 **주소 부분만** 바꾼다. 예를 들어 `http://100.101.102.103:8000/#game=...`에서 `100.101.102.103`만 자신의 목록에 표시된 주소로 바꾸고 `:8000/#game=...`은 유지한다. 이후에는 바꾼 주소를 계속 사용한다. ([공유된 머신의 IPv4 주소](https://tailscale.com/docs/features/sharing))

## 3. 새로고침과 재접속

새로고침하거나 탭을 닫았다 열 때는 **같은 방 링크와 같은 브라우저·프로필**을 사용한다. 서버 첫 화면의 **마지막으로 있던 방으로 이어 하기** 버튼으로 돌아올 수도 있다.

좌석은 그 브라우저의 쿠키에 연결된다. 같은 이름을 입력하는 것만으로 자리를 되찾지는 못한다. 다른 브라우저·프로필·시크릿 창은 별개의 접속이므로, 쿠키를 지웠거나 다른 기기로 옮겼다면 호스트에게 기존 좌석을 비워 달라고 한 뒤 다시 앉는다.

기존 브라우저를 사용할 수 있으면 상단 **좌석** → **자리 비우기**로 직접 반납한 뒤 새 기기에서 다시 앉아도 된다.

Wi-Fi가 끊기거나 노트북이 잠들어 접속 표시가 꺼져도 좌석 자체는 유지된다. 연결을 복구하고 같은 주소와 브라우저로 돌아온다. 주소를 IP에서 다른 이름으로 바꾸면 쿠키가 따라가지 않으므로 처음 접속한 주소를 계속 사용한다.

## 4. 서버가 중단됐을 때

**서버 연결 끊김**이 표시되면 자신의 인터넷·Wi-Fi와 Tailscale 연결을 확인한다. 자신의 연결에 문제가 없으면 호스트에게 서버가 실행 중인지 확인해 달라고 한다.

**새 방 링크로 들어오세요**가 표시되면 호스트가 복구를 마치고 보내는 **새 방 링크**를 사용한다. 저장을 불러온 방은 주소의 게임 ID가 바뀌므로 예전 방 링크로 돌아갈 수 없다. 새 방에서 이름을 입력하고 원래 사용하던 좌석에 다시 앉는다.

## 5. 접속 문제 해결

| 증상 | 플레이어가 할 일 |
|---|---|
| 방 링크가 열리지 않음 | 같은 LAN 또는 Tailscale에 연결됐는지 확인하고, 호스트에게 서버 실행 여부와 링크 주소 확인 요청 |
| Tailscale 기기 목록에 호스트가 없음 | 머신 공유 초대를 수락했는지 확인하고 호스트에게 공유 상태 확인 요청 |
| Tailscale 기기는 보이는데 링크가 안 열림 | 목록의 호스트 IP와 방 링크의 IP 비교; 다르면 주소 부분만 교체 |
| 초대받은 사람만 들어올 수 있다는 첫 화면 | 호스트에게 받은 `/#game=...`까지 포함한 방 링크 사용 |
| 내 자리가 이미 점유됐다고 나옴 | 처음 앉은 브라우저·프로필로 접속. 쿠키를 잃었다면 호스트에게 **좌석 비우기** 요청 후 다시 앉기 |
| 빈 좌석이 없음 | 호스트에게 사람 좌석 수와 다른 참가자의 점유 상태 확인 요청 |
| 화면 갱신이 멈추거나 **서버 연결 끊김** 표시 | 자신의 연결 복구 후 같은 방 링크로 새로고침. 계속되면 호스트에게 확인 요청 |
| **새 방 링크로 들어오세요** 표시 | 호스트에게 새 방 링크를 받아 다시 접속하고 좌석 선택 |
| 카드·보드 그림이 없음 | 텍스트 UI로 계속 접속 가능. 이미지 준비 여부는 호스트에게 확인 |

접속 문제를 호스트에게 알릴 때는 사용한 브라우저, 같은 LAN인지 Tailscale인지, 화면에 표시된 메시지를 함께 전달한다.
