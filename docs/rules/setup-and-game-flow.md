# Uprising 4인 setup과 game flow

이 문서는 **Dune: Imperium - Uprising 기본 게임의 4인 플레이**를 위한 구성물, setup, 라운드 흐름, 턴 순환, 종료 조건만 정리한다. CHOAM 표시가 있는 구성물과 Shaddam Corrino IV는 CHOAM 모듈을 사용하지 않는 이 범위에서 제외한다. [Main p. 3] [Main p. 4]

규칙 문장은 공식 메인 룰북과 2025년 1월 13일 FAQ를 짧게 바꾸어 썼다. FAQ가 메인 룰을 보강한 경우 두 출처를 함께 표시한다.

## 1. 구성물

### 플레이어별 구성물

- 각 색상에는 Agent 3개, Control marker 3개, Combat marker 1개, cube 16개, disc 2개, Score marker 1개, Councilor token 1개, Spy 3개가 있다. [Main p. 3]
- 각 플레이어의 시작 덱은 10장이다: Convincing Argument 2장, Dagger 2장, Diplomacy 1장, Dune, the Desert Planet 2장, Reconnaissance 1장, Seek Allies 1장, Signet Ring 1장. [Main p. 3]
- cube 16개 가운데 4개는 네 Faction의 Influence marker이고, 나머지 12개는 troop이다. [Main p. 5]

### 공용 보드와 카드

- 양면 game board 1개, Board Space Guide 1장, Shield Wall 1개, Alliance token 4개, Maker Hooks 4개, First Player marker 1개를 사용한다. [Main p. 3]
- 상자에는 Leader 9장이 있으며 그중 1장은 CHOAM 모듈 전용이다. 기본 게임 setup에서는 Shaddam Corrino IV를 선택하지 않는다. [Main p. 3] [Main p. 4]
- Imperium 카드는 69장이며 이 가운데 CHOAM 표시 4장을 기본 게임에서 제외한다. Intrigue 카드도 44장 가운데 CHOAM 표시 4장을 제외한다. [Main p. 3] [Main p. 4]
- Reserve는 Prepare the Way 8장과 The Spice Must Flow 10장, 총 18장이다. [Main p. 3]
- Conflict 카드는 I 3장, II 9장, III 4장으로 총 16장이고, 실제 게임에는 setup에서 고른 10장만 사용한다. [Main p. 3] [Main p. 4]
- Objective 카드는 5장이다. 네 명에게 맞지 않는 인원수 표시 카드는 setup에서 제외한다. [Main p. 3] [Main p. 5]

### 자원과 sandworm

- Solari는 가치 5인 token 8개와 가치 1인 token 20개, spice는 가치 5인 token 7개와 가치 1인 token 20개, water는 20개가 들어 있다. [Main p. 3]
- sandworm은 플라스틱 4개와 나무 4개가 제공되며 원하는 종류를 골라 쓰거나 함께 쓸 수 있다. Feyd-Rautha Harkonnen을 위한 Feyd token도 포함된다. [Main p. 3]
- Solari, spice, 남은 water와 사용할 sandworm을 보드 옆 bank에 둔다. 이들 수량은 제한으로 보지 않아 모자라면 대체물을 사용할 수 있다. Maker Hooks 4개도 bank에 둔다. [Main p. 5]

## 2. 4인 game setup

### 보드와 공용 token

1. 기본 게임에 지정된 면으로 game board를 놓는다. [Main p. 4]
2. Shield Wall을 Spice Refinery 아래의 표시된 위치에 놓는다. [Main p. 4]
3. Emperor, Spacing Guild, Bene Gesserit, Fremen Influence track의 표시된 위치에 각 Alliance token을 놓는다. [Main p. 4]

### Conflict deck

1. Conflict 카드를 I, II, III 뒷면별로 나눈다. [Main p. 4]
2. Conflict III 4장을 섞어 모두 뒷면으로 놓는다. [Main p. 4]
3. Conflict II 9장을 따로 섞고 그중 5장을 Conflict III 위에 뒷면으로 놓는다. [Main p. 4]
4. Conflict I 3장을 따로 섞고 그중 1장을 맨 위에 뒷면으로 놓는다. [Main p. 4]
5. 완성된 덱은 위에서부터 I 1장, II 5장, III 4장이다. 사용하지 않는 I와 II 카드는 앞면을 보지 않고 상자로 돌려보낸다. [Main p. 4]

### 카드 공급처와 Leader

1. CHOAM 표시 카드를 뺀 Intrigue deck을 섞어 뒷면으로 놓는다. [Main p. 4]
2. CHOAM 표시 카드를 뺀 Imperium deck을 섞어 뒷면으로 놓고, 위에서 5장을 공개해 Imperium Row를 만든다. [Main p. 4]
3. Imperium Row 옆에 Prepare the Way와 The Spice Must Flow를 종류별 Reserve stack으로 놓는다. Uprising setup에는 Foldspace stack이 없다. [Main p. 4] [Main p. 5]
4. 각 플레이어는 CHOAM 모듈 전용 Shaddam을 제외한 Leader를 선택하거나 무작위로 받아 공개해 둔다. [Main p. 4]
   - Feyd-Rautha Harkonnen을 선택했다면 Feyd token을 Leader의 Training track 맨 왼쪽 칸에 놓는다. [Main p. 17]
   - Lady Jessica를 선택했다면 Reverend Mother Jessica가 아닌 Lady Jessica 면으로 시작한다. [Main p. 17]
5. 각 플레이어는 자기 10장 시작 덱을 섞어 Leader 왼쪽에 뒷면으로 놓는다. [Main p. 5]

### 플레이어 상태

1. 각 플레이어는 색상을 하나 정하고 그 색의 구성물을 가져간다. [Main p. 5]
2. Agent 2개는 Leader 위에 놓고, 세 번째 Agent인 Swordmaster는 game board 옆에 둔다. Uprising에는 Mentat Agent가 없다. [Main p. 5] [Main p. 6]
3. 4인 게임에서는 disc 하나를 Score track의 1에 놓고 Combat marker를 0에 놓는다. [Main p. 5]
4. 각 Faction Influence track의 맨 아래에 자기 cube를 하나씩 놓는다. [Main p. 5]
5. troop 12개 중 3개는 자신과 가장 가까운 garrison에 놓고 나머지는 자기 supply에 둔다. [Main p. 5]
6. 각 플레이어는 water 1개를 받고, Spy와 남은 개인 구성물을 다른 플레이어가 수량을 볼 수 있도록 supply에 둔다. [Main p. 5]

### Objective와 첫 플레이어

1. Objective 중 4인 게임과 맞지 않는 인원수 표시 카드를 제외하고 나머지를 섞는다. [Main p. 5]
2. 각 플레이어는 Objective를 무작위로 한 장 받아 자기 supply에 앞면으로 공개한다. [Main p. 5]
3. Objective에 First Player marker가 표시된 플레이어가 그 marker를 가져간다. [Main p. 5]

## 3. 일반 개념

### 자원과 Victory Point

- 기본 자원은 Solari, spice, water다. 자원을 얻으면 bank에서 가져오고 비용을 내면 bank로 돌려보낸다. [Main p. 20]
- Victory Point를 얻거나 잃을 때마다 Score marker를 같은 수만큼 이동한다. [Main p. 6] [Main p. 20]
- Score track 그림이 12까지만 있어도 실제 점수는 12를 넘을 수 있다. [FAQ p. 4]

### 개인 덱과 Agent

- 새로 얻은 Imperium 또는 Reserve 카드는 먼저 자기 discard pile에 놓는다. 카드를 뽑아야 하는데 deck이 비어 있으면 discard pile을 섞어 새 deck을 만든 뒤 남은 수만큼 계속 뽑는다. [Main p. 6]
- trash된 카드는 그 게임 동안 개인 덱에서 제거된다. [Main p. 6]
- 각 플레이어는 Agent 2개로 시작하며 게임 중 세 번째 Agent를 얻을 수 있다. Agent를 보드 공간으로 보내려면 이를 허용하는 카드를 먼저 사용해야 한다. [Main p. 6]

### First Player marker

- 첫 라운드의 First Player는 공개된 Objective로 결정한다. [Main p. 5]
- 게임이 계속될 때 Recall 단계에서 First Player marker를 시계 방향의 다음 플레이어에게 넘긴다. [Main p. 15]

## 4. 라운드 phase 개요

- 각 라운드는 `Round Start`, `Player Turns`, `Combat`, `Makers`, `Recall`의 다섯 phase를 이 순서로 진행한다. [Main p. 8]
- Round Start에는 새 Conflict를 공개한 뒤 각 플레이어가 개인 deck에서 카드 5장을 뽑는다. [Main p. 8]
- Player Turns에는 First Player부터 시계 방향으로 Agent turn 또는 Reveal turn을 한 번씩 번갈아 수행한다. [Main p. 8]
- Combat에서는 먼저 참가자가 Combat Intrigue를 사용할 기회를 가진 뒤 현재 Conflict의 순위와 보상을 해결한다. [Main p. 14]
- Makers에서는 Agent가 없는 Maker 공간에 bonus spice 1개씩을 추가한다. 이미 놓인 bonus spice가 있으면 누적된다. [Main p. 15]
- Recall에서는 종료 조건을 검사하고, 게임이 계속되면 Agent 회수와 First Player 교대를 수행한다. [Main p. 15]

## 5. Round Start

1. Conflict deck 맨 위 카드를 공개해 지정된 자리에 놓는다. 이전 라운드에서 보드에 남은 Conflict 카드가 있으면 그 위에 새 카드를 놓는다. [Main p. 8]
2. 새 Conflict가 자신이 이미 control하는 장소에 관한 카드라면, 그 플레이어는 자기 supply의 troop 1개를 Conflict에 배치할 수 있다. [Main p. 20]
3. 각 플레이어는 자기 deck에서 카드 5장을 뽑아 이번 라운드 hand를 만든다. [Main p. 8]
4. 이전 Reveal turn이 끝난 뒤 뽑아 보관한 카드가 있더라도 이번 Round Start에 카드 5장을 추가로 뽑는다. 즉, hand를 5장으로 맞추는 절차가 아니다. [Main p. 8] [FAQ p. 3]

## 6. Player Turns 순환

1. First Player부터 시작해 시계 방향으로 한 번에 한 turn씩 진행한다. [Main p. 8]
2. 자기 turn에는 Agent turn 또는 Reveal turn 중 하나를 선택한다. Agent가 남아 있어도 Agent turn을 포기하고 Reveal turn을 시작할 수 있다. [Main p. 8]
3. Reveal turn을 마친 플레이어는 이 phase의 이후 차례를 모두 건너뛴다. [Main p. 8]
4. 네 플레이어가 모두 Reveal turn을 마치면 Player Turns phase가 끝나고 Combat phase로 진행한다. [Main p. 8]
5. Plot Intrigue는 자신의 Agent turn이나 Reveal turn 도중 사용할 수 있다. 카드의 조건과 비용은 충족해야 하며, 다음 Reveal turn에 적용되는 효과라면 그때까지 카드를 앞면으로 유지한 뒤 사용하고 버린다. [Main p. 7] [Main p. 8] [FAQ p. 2]

### Agent turn 요약

- hand에서 카드 1장을 공개해 사용하고, 그 카드의 Agent icon 중 하나와 맞는 보드 공간에 Leader의 Agent 1개를 보낸다. 일반적으로 이미 Agent가 있는 공간에는 갈 수 없지만 Spy 등 명시된 예외가 우선한다. [Main p. 9]
- 공간의 비용과 요구조건은 카드나 공간 효과를 해결하기 전에 충족해야 한다. 비용을 즉시 낼 수 없으면 그 공간을 선택할 수 없다. [Main p. 9]
- 이 turn에는 사용한 카드의 Agent box만 적용하고 Reveal box는 적용하지 않는다. Agent icon이 없는 카드는 Agent turn에 사용할 수 없다. [Main p. 8] [Main p. 9]
- 공간 효과, 카드의 Agent box, Faction 공간 방문으로 얻는 Influence는 원하는 순서로 해결할 수 있다. [Main p. 9]

### Reveal turn 요약

1. hand에 남은 카드를 모두 앞면으로 공개하며, 앞서 Agent turn에 사용한 카드와 구분해 둔다. [Main p. 12]
2. 방금 공개한 카드의 Reveal box만 해결한다. 효과 순서는 플레이어가 정하며, 카드 획득은 Reveal 효과의 전, 사이, 후에 끼워 넣을 수 있다. [Main p. 12]
3. Persuasion은 여러 출처를 합치거나 나누어 Imperium Row와 Reserve의 카드를 얻는 데 쓸 수 있다. 쓰지 않은 Persuasion은 Reveal turn 끝에 사라지고, Imperium Row의 빈자리는 즉시 보충한다. [Main p. 13]
4. Conflict strength는 Reveal 효과를 해결하는 동안 필요한 시점에 설정하고 변화가 생기면 갱신한다. 별도의 고정된 strength 단계는 아니다. [Main p. 12] [Main p. 13]
5. Reveal turn 도중 카드를 뽑으면 즉시 그 카드를 공개하고 이번 Reveal turn에 사용한다. Reveal turn이 끝난 뒤 뽑은 카드는 다음 라운드까지 hand에 보관한다. [FAQ p. 3]
6. 마지막으로 이번 라운드의 Agent turn과 Reveal turn에 앞면으로 낸 카드를 자기 discard pile에 놓는다. [Main p. 12]

## 7. Recall과 게임 종료

### 다음 라운드로 진행

- Makers가 끝난 뒤 종료 조건이 충족되지 않았다면 모든 Agent를 소유자의 Leader로 돌려보낸다. [Main p. 15]
- First Player marker를 시계 방향의 다음 플레이어에게 넘기고 새 라운드의 Round Start를 시작한다. [Main p. 15]

### 종료 조건과 최종 점수

- 라운드가 끝났을 때 한 명 이상이 10 Victory Point에 도달했거나 Conflict deck이 비어 있으면 Endgame을 시작한다. 라운드 도중 10점에 도달한 순간에 바로 끝내는 절차는 아니다. [Main p. 6] [Main p. 15]
- Endgame Intrigue를 사용하고 해결한 뒤 Victory Point가 가장 높은 플레이어가 승리한다. [Main p. 15]
- Endgame에는 wild battle icon 하나를 supply의 세 battle icon 종류 중 하나와 짝지어 두 카드를 뒤집고 1 Victory Point를 얻을 수 있다. [Main p. 20]
- Victory Point가 같으면 spice, Solari, water, garrison의 troop 수를 차례로 비교한다. [Main p. 15]
- 위 네 비교가 모두 같으면 가장 최근에 Reveal turn을 수행한 플레이어가 최종 승자가 된다. 이 항목은 FAQ가 메인 룰북의 동률 규칙을 보강한다. [Main p. 15] [FAQ p. 2]

## 8. 이 문서에서 확정하지 않은 항목

- CHOAM 모듈의 계약, 모듈 전용 카드, Shaddam setup은 이 4인 기본 게임 문서의 범위 밖이다. [Main p. 3] [Main p. 4]
- Agent turn의 Spy, troop 배치, sandworm, Shield Wall과 각 보드 공간의 상세 효과는 별도 시스템 규칙으로 남긴다. [Main p. 9]
- Combat의 참가 조건, Intrigue 우선권, 순위·동률·보상 해결은 이 문서에서 상세 판정을 정하지 않는다. [Main p. 14]
- Makers의 개별 공간 효과와 bonus spice 획득 방식은 이 문서에서 다루지 않는다. [Main p. 15] [Main p. 20]
- 메인 룰은 Endgame Intrigue를 해결한 뒤 점수를 비교한다고 설명하지만, 플레이어 사이의 Endgame Intrigue 해결 순서와 wild battle icon 처리와의 상대적 순서는 명시하지 않는다. 이 문서에서는 별도 순서를 만들지 않는다. [Main p. 15] [Main p. 20]
- 제공된 규칙 본문은 Imperium deck이 완전히 고갈되어 Imperium Row를 다섯 장으로 보충할 수 없는 경우를 설명하지 않는다. 이 문서에서는 판정을 만들지 않는다. [Main p. 13]
