# 선택 불가 표시와 자동 처리 없애기 — 남은 작업 계획

기준일: 2026-09-30 (master `6878111` 기준 코드 위치). 이 문서는 다른 세션에서 이어 작업하기 위한 인계서다. 조사 원자료는 세션 스크래치(휘발)에만 있었으므로 필요한 사실을 여기에 옮겼다.

## 1. 목적과 원칙

사용자 요청:

- 2026-09-29: "지금 고를 수 없는 선택지를 이유와 함께 회색으로 보여 줍니다 → 이거 아라킨 스카웃 말고 전체 게임에도 적용했으면 좋겠어." 고를 수 없는 선택지는 보이되 누를 수 없고, 턴 안에서 가능해지면 곧바로 누를 수 있게, 반대로 불가능해지면 다시 누를 수 없게 바뀐다.
- 2026-09-30: 3단계는 전부 한다("하지 않기를 권하는 것 → 이것들도 다 해야된다고 봐"). 결정 창 없이 자동으로 넘어가는 곳도 모두 결정 창을 연다("플레이어가 직접 체크하는게 플레이하는데에는 도움이 될 것 같아"). 사막의 힘은 (B).

원칙(1단계에서 확립, `src/dune_imperium/display/unavailable.py` 모듈 문서):

1. 합법성은 오직 `engine.legal_actions`다. 표시 코드는 합법 목록을 바꾸지 않는다.
2. 이유는 그 선택지를 거르는 공급자(provider)가 쓰는 막힘 판정을 그대로 노출한 함수에서 온다(공급자는 `block is None`을 계속 쓴다). 따로 다시 계산하지 않는다.
3. 합법 행동과 같은 후보는 서버가 버린다. 판정이 어긋나도 회색 줄이 숨을 뿐, 할 수 있는 것을 회색으로 만들지 않는다.
4. 합법이 아닌 행동은 절대 dry-run하지 않는다.
5. 결정하는 좌석에게만 보낸다. 숨은 영역을 다시 섞어도(`agents.determinize`) 결과가 같아야 한다(누출 방지 테스트).
6. 이유를 못 찾으면 일반 문구("지금은 고를 수 없음")로 떨어지는데, 일관성 테스트가 이것을 실패로 잡는다.

**자유 순서 문구(2026-09-29 조사에서 발견).** Agent 효과 목록에서 "지불 안 함"만 남은 경우의 10~28%는 같은 차례의 다른 효과를 먼저 풀면 가능해진다(효과는 원하는 순서로 `[Main p. 9]`). 예: 스파이스 0인 레이디 제시카가 하가 분지에 가면, 수확을 먼저 하면 스파이스의 고통을 낼 수 있다. 지금은 "지불 안 함"을 먼저 누르면 기회가 사라진다. 그래서 Agent 효과 frame의 회색 줄은 다른 효과가 아직 남아 있으면 "지금 스파이스 2 (4 필요) — 이번 차례의 다른 효과로 채우면 가능"처럼 쓰고, 남은 효과가 없을 때만 "4 필요 (보유 2)"로 쓴다. 정확한 "가능해질지" 판정은 모든 효과를 dry-run해야 하므로 하지 않고, "다른 효과가 남았는가"만 본다.

## 5. 자동 처리 없애기 — 결정 창을 연다

## 6. 숨은 정보 문제 (별도 작업, 고위험)

교전이 끝날 때 병력을 3개 이상 잃은 좌석 가운데 Harvest Cells(세포 수확)를 가진 좌석에게만 사용 창이 열리고, 공개 이벤트 `conflict_end_trigger_offered`(화면 "교전 종료 발동 책략 제안")가 좌석을 밝힌다(`rules/combat.py:1196-1246`, `content/uprising/intrigue.py:1353-1370`, `server/session_log.py`는 이 종류를 가리지 않음). 거절해도 그 카드를 가졌다는 사실이 드러난다. Combat Intrigue처럼 해당하는 모든 좌석에게 묻거나(카드 없는 좌석은 패스) 좌석을 밝히는 이벤트를 없앤다. 불멸 게임에서 40판에 2~6번 제안, 거절로 드러나는 경우는 드묾. 2026-09-30 사용자: "수정하긴 해야겠네." 세션 작업 제안 칩으로 따로 띄워 두었다.
