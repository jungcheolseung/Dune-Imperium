기본 대상은 **Dune: Imperium - Uprising 4인 게임**입니다. 사람이 한 명이어도 남은 세 좌석을 AI로 채워
플레이할 수 있습니다. 이는 공식 솔로 모드를 구현한 것과는 다른 플레이 방식입니다.

## 게임 구성

| 구성 | 현재 범위 |
| --- | --- |
| Uprising | 4인 기본 게임 |
| CHOAM Module | 게임 생성 시 선택 |
| Bloodlines | 확장과 Tech Module을 선택 |
| Immortality | 확장과 Go to 11 변형을 선택 |
| Epic Game Mode | Rise of Ix의 에픽 게임 모드만 지원; Rise of Ix 확장 전체는 지원하지 않음 |
| Arrakeen Scouts | Uprising 4인 엔진에서 선택하는 모듈 |
| 프로모·지도자 드래프트 | 지원 프로모와 공개 드래프트를 선택; 공개 드래프트는 프로젝트 자체 운영 방식 |

공식 Rivals 솔로·2인 모드, 공식 3인 구성, 6인 팀전은 현재 구현 대상이 아닙니다.
옵션을 켜는 위치는 [처음 한 판]({{< relref "guides/first-game.md" >}})에서 안내합니다.

## 플레이 기능

- 사람과 AI를 섞은 네 좌석 구성, AI끼리 플레이하는 판 관전.
- 호스트가 여는 방에 링크로 참여하는 멀티플레이.
- 한국어·영어 화면, 가능한 행동 안내와 도움말.
- 저장·불러오기, 자동 저장, 끝난 판의 리플레이 검토.
- 숨은 정보가 새로 드러나기 전 등 허용되는 범위의 되돌리기.

AI 종류와 필요한 준비물은 [AI 고르기]({{< relref "guides/choosing-ai.md" >}})를 보세요.

## 실행 환경의 확인 범위

| 환경 | 현재 확인 상태 |
| --- | --- |
| macOS | Mac mini에서 서버 런처와 운영 경로 확인 |
| Windows 네이티브 | Windows 11에서 런처 시작·중지, 로컬·원격 서버, 앱 AI 대전·저장, 원격 좌석 참여, 강제 종료 뒤 복구 확인(2026-10-12). 다른 PC에서의 접속·화면 배율·한글 입력은 남음 |
| Linux | CLI 실행 경로 안내, 별도 실기 검증은 남음 |
| WSL2 | 기본 안내 범위 밖; 창·네트워크 설정을 별도로 확인해야 함 |
| 참가자 브라우저 | 최신 데스크톱 브라우저와 쿠키 사용을 전제로 안내 |
| 모바일만으로 게임 진행 | 검증하지 않음 |

위 표는 기능의 구현 여부와 실제 기기에서 확인한 범위를 구분한 것입니다.
웹사이트가 휴대폰에서 읽히더라도 게임 화면의 모바일 플레이를 보장하지는 않습니다.

## 별도로 준비할 수 있는 항목

카드·보드 원본 이미지와 학습 모델은 소스에 포함하지 않습니다. 그림이 없으면 텍스트 화면으로 시작할 수 있고,
기본 AI는 별도 학습 모델 없이 사용할 수 있습니다. 탐색 AI는 지금 엔진의 행동 버전에 맞게 학습한 모델과 추가 의존성이 필요하며, 공개하는 모델 파일은 아직 없습니다.
