## The earliest code

The repository's first records date to March 2023. Initial data classes were followed by separate player and game state in April, along with starting-card definitions.

On April 10 the code moved into the `dune` package with Poetry configuration and a test folder. This was a small starting structure.

## Scope at this point

These commits did not yet provide complete games or AI training. Work on the current Uprising engine and learning environment begins in the August 2026 records.
