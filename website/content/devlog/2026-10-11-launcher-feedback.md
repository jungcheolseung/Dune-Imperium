## 서버를 창에서 켜고 끄기 (10월 8–9일)

플레이 서버는 터미널 명령으로 켰습니다. 목표는 Mac과 Windows에서 터미널 없이 창으로 서버를 켜고 끄는 것이었고, 다섯 안 가운데 tkinter 창을 골랐습니다. 1단계부터 6단계까지 10월 9일에 병합했습니다.

- **창.** 왼쪽은 설정(모드, 주소 후보, 포트, 방 링크 앞부분, 저장 폴더, 탐색 망, AI 속도, 그림)이고 오른쪽은 시작·중지, 시작 전 검사, 방 링크의 복사와 열기, 열린 게임 목록, 서버 로그입니다. 설정은 git에 올리지 않는 로컬 폴더에 둡니다.
- **서버가 도는 동안의 동작.** 호스트 PC가 잠들지 않게 막고(macOS와 Windows 각각의 방법), 체크아웃마다 런처를 하나만 띄웁니다. 더블클릭으로 여는 바로가기(`.app`, `.lnk`)를 만드는 스크립트도 있습니다.
- **서버 쪽 옵션.** 런처가 띄운 서버가 런처보다 오래 살지 않도록 `--exit-when-stdin-closes`를 넣었습니다. 런처가 죽으면 표준 입력이 닫히고, 서버는 그걸 보고 스스로 종료합니다(Windows는 Job Object도 씁니다).
- **정정.** 탐색 AI 좌석은 학습 도구(torch)만 확인하고 좌석을 내놓았다가, 막상 앉히면 실패했습니다. 이제 `rl` 패키지(numpy 등)까지 있어야 좌석을 제공하고, 설치 스크립트와 안내서도 두 extra를 함께 받도록 고쳤습니다.

검증 위험도는 둘로 나눴습니다. 창의 모양(`gui.py`, `view.py`)은 저위험이고, 서버를 띄우고 내리는 쪽(`supervisor.py`, 표준 입력 종료)은 고위험이라 단계마다 독립 리뷰를 받았습니다. 1·2·3–5단계 리뷰 모두 실제 결함을 찾아 고쳤습니다. 확인은 `tests/launcher/` 192개(창 테스트는 화면이 없으면 건너뜀), 런처 링크 브라우저 E2E 16검사, macOS와 Windows 대상 mypy이고, 병합한 master의 전체 pytest는 6,932개, E2E는 54종입니다. 이 Mac에는 화면 기록 권한이 없어 창 캡처는 하지 못했습니다.

10월 11일에는 로컬 모드의 자동 저장을 더했습니다. 런처의 "이 컴퓨터에서만" 모드로 혼자 AI와 둔 판이 런처를 닫자 사라졌기 때문입니다. 자동 저장이 원격 서버에만 있었던 탓이고, 서버의 `--autosave`가 원격 없이도 같은 방식의 저장을 켜게 했습니다. 직접 손으로 띄우는 서버의 기본값은 그대로입니다.

Windows 쪽 확인은 10월 12일에 별도 Windows 11 PC에서 했습니다. 런처 버튼에서 서버 프로세스까지 정상 중지하는 통합 회귀를 추가하고, 일반 계정에서 심볼릭 링크를 만들 수 없는 테스트 실패 등을 고친 뒤 실제 Chrome E2E 174검사가 통과했습니다(런처 링크, 앱 AI 좌석, 원격, 복구). 이 변경은 10월 21일에 master에 병합했습니다. 다른 PC에서의 접속, 화면 배율과 입력기, 장시간 사용 같은 수동 검사는 남아 있어 런처 계획의 마지막 단계를 완료로 표시하지는 않았습니다.

## 게임다운 연출과 AI 속도 (10월 8일)

플레이 화면에 진짜 게임 같은 연출을, 전투 단계가 끝나면 최종 순위를, AI의 차례에도 플레이어 차례처럼 안내를 더하기로 했습니다. AI의 수는 사람이 한 번 누를 때 한꺼번에 끝나서, 화면에는 AI가 두는 "지금"이 없었습니다. 1–5단계를 같은 날 병합했습니다.

- **연출 한 줄.** 차례 띠와 카드 알림을 하나의 큐가 로그 순서대로 한 번에 하나씩 올립니다. AI 차례 띠, Agent 카드가 놓일 때 칸이 좌석 색으로 빛나는 효과, Reveal한 카드의 부채꼴, 좌석 패널의 숫자 변화(+2, −1), 모래벌레 소환과 방어벽 파괴 띠, 전투 결과판, 게임 끝의 최종 순위판이 있습니다.
- **AI 진행 속도.** 사람 좌석이 있는 판의 AI 결정은 화면이 앞의 일을 보여 줄 시간이 지난 뒤 적용합니다. 서버의 `--ai-pace` 기본값은 보통이고, 빠르게(0.6배)와 즉시(예전 방식)가 있습니다. 답은 바뀌지 않아 같은 시드의 즉시 판과 같은 상태에 닿는다는 것을 테스트합니다. AI만 있는 판은 늘 즉시입니다.

### 보고 전용 이벤트

전투 순위(`combat_standing`)와 Reveal한 카드 목록(`cards_revealed`)은 화면에 필요한 사실이지만 규칙의 상태는 아닙니다. 이것을 상태의 이벤트 기록에 넣으면 상태 해시가 달라져 옛 저장이 열리지 않습니다. 그래서 서버 로그에는 가지만 상태에는 남지 않는 "보고 전용 이벤트"로 만들었습니다. 처음에는 이벤트 기록에 넣었다가, 병합 직전에 저장된 게임을 불러 보고 해시 대조에 막힌 것을 찾았습니다. 그 뒤로 화면용 이벤트는 처음부터 보고 전용으로 만든다는 교훈을 `docs/lessons.md`에 남겼습니다.

4단계의 독립 리뷰는 속도 조절 중인 일반 AI가 탐색 AI용 대체 답을 써서 에이전트 오류를 덮고, 그 판의 저장이 열리지 않게 되는 결함을 찾았습니다. 이제 탐색 좌석만 대체 답을 씁니다. 이 단계의 확인은 pytest 6,676개와 E2E 50종입니다. 구매한 카드의 이동, 동맹 띠와 영향력 큐브, 라운드 정리 연출, 연출 끄기 설정은 미뤘고, 원격 판에서 보통 속도로 실제 두어 본 확인은 아직 없습니다.

## 친구들과 둔 판 뒤의 수정 (10월 11일)

10월 11일 낮과 밤에 친구들과 둔 두 판에서 나온 피드백을 항목별로 고쳤습니다. 엔진, codec, 저장 형식은 바꾸지 않았습니다.

- **플레이 시계.** 체스 시계처럼 제어권을 쥔 좌석의 시간을 셉니다. 남의 턴에 끼어드는 답, 턴 밖 결정, "턴 종료 ▶"를 누르기 전까지가 모두 그 좌석의 몫이고, AI 좌석도 똑같이 셉니다. 되돌리기는 시간을 돌려주지 않습니다. 저장에는 선택 필드로 남기며, 기보와 문제집은 이 필드를 읽지 않습니다(시간은 학습 데이터로 쓰지 않는다는 결정). 무작위로 둔 27판, 약 600번의 조작을 매번 대조한 리뷰에서 큰 문제는 없었고, 아주 큰 시계 값의 저장이 열리지 않는 결함 하나를 고쳤습니다.
- **소리.** 결정할 차례, 라운드 시작, 전투 시작, Arrakeen Scouts에 소리를 넣었습니다. 소리는 코드로 합성한 것만 쓰고(소리 파일을 에셋에 두지 않는다는 결정) 서로 다른 음으로 구분했습니다.
- **열 너비와 손패 순서.** 좌석, 보드, 결정 열 사이의 손잡이를 끌어 너비를 바꿀 수 있고 손패와 책략의 순서도 끌어서 바꿀 수 있습니다. 둘 다 브라우저에만 저장되며 서버로 가지 않습니다.
- **더미 목록 창.** 버림 더미와 덱 목록이 카드 확대와 같은 팝오버를 써서, 목록 안 카드에 마우스를 올리면 확대가 목록을 덮고 갱신마다 목록이 닫혔습니다. 목록을 자기 창으로 옮기고 ×, Esc, 같은 버튼으로만 닫히게 했습니다.
- **이번 차례의 카드.** 이번 Agent 턴에 낸 카드를 표시하고, 카드를 폐기하면 그 카드의 에이전트 칸에 남은 효과가 사라진다는 경고를 폐기 행에 붙입니다. 리뷰에서 무작위 1,200판의 폐기 행 8,272개를 대조해 경고와 실제 효과 소멸이 모두 일치했고, 숨은 정보를 다시 섞어도 결과가 같았습니다.
- **Scouts 큰 창.** 공개된 Arrakeen Scouts 항목을 보드 위의 카드로 보여 주고, 접기와 펼치기, 한 라운드의 여러 항목 사이 이전·다음 이동을 지원합니다. 문구는 직접 쓴 의역입니다. 비밀 선택의 공개 단계에서는 아직 공개되지 않은 좌석을 "아직 비공개"로 따로 적어, 엔진은 맞는데 공개처럼 읽히던 오해를 없앴습니다.
- **승점 기록.** 좌석 패널의 승점을 누르면 그 좌석의 승점 변화(라운드, 증감, 누계, 원인)를 보여 주고, 줄을 누르면 활동 로그의 그 수로 갑니다. 서버가 판을 다시 따라가 수마다 승점 차이를 계산합니다. 원격에서는 좌석에 앉은 사람이나 끝난 판에서만 볼 수 있습니다.
- **아이콘 하나가 효과 하나.** 룰북의 아이콘 하나는 효과 하나입니다(`[Main p. 20]`). 로그와 선택 줄에서 아이콘 둘을 겹쳐 쓰던 문구를 의미에 맞는 아이콘 하나로 바꿨습니다.
- **카드 그림 보기.** 활동 로그의 카드 이름이나 카드를 고르는 행에 마우스를 올리면 카드 그림이 뜹니다.
- **한국어 이름.** 게임판 장소 23곳과 목적 카드 5장의 한국어 이름을, 공식 한글판 게임판 안내서(`[Board Guide pp. 1-2]`)와 짝지어 선택 줄, 로그, 보드 툴팁에 씁니다. 보드 그림 자체는 영어판 그대로입니다. 지도자 능력, 인장 반지, Navigation 카드도 공식 한글판의 이름으로 맞췄습니다. 도움말의 영어 병기는 의도적으로 남겼습니다.

이 묶음의 확인은 pytest 7,267에서 7,301개까지(작업마다), ruff와 mypy, 브라우저 E2E 56종에서 59종까지였습니다.

같은 시기 사람이 둔 판을 현재 엔진으로 옮겨 진단하고 문제집을 만든 작업은 [사람이 둔 판을 기보와 문제집으로]({{< relref "devlog/2026-10-11-human-records.md" >}})에, 플레이에서 나온 규칙 질문과 판정은 [규칙 질문 글]({{< relref "devlog/2026-10-14-rule-questions.md" >}})에 따로 정리했습니다.
