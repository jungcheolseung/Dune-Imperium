화면은 현재 결정할 플레이어와 가능한 행동을 안내합니다. 진행이 멈춘 것처럼 보이면
남은 선택이나 **턴 종료 ▶**, **확정 ▶** 버튼이 있는지 먼저 확인하세요.

## 한 턴 진행하기

에이전트를 보내는 차례에는 손패의 사용할 카드와 보드 칸을 고르고, 남은 선택을 해결합니다.
화면에서 빛나는 카드·칸으로 가능한 선택을 확인할 수 있습니다. 선택을 취소할 때는 `Esc`를 사용할 수 있습니다.

공개 차례에는 카드를 공개한 뒤 남은 설득력으로 획득할 카드를 고릅니다.
할 일을 마치면 **턴 종료 ▶**를 눌러 다음으로 넘어갑니다.

일부 선택은 먼저 고른 상태로 화면에 남고 **확정 ▶**를 눌러 보내도록 되어 있습니다.
내 차례가 아니더라도 응답해야 하는 선택이 있을 수 있으니 화면의 안내를 따라 주세요.

## 되돌리기

되돌리기는 내 연속 행동 중 허용된 범위에서 사용할 수 있습니다. 새로운 무작위 결과나 숨겨진 정보가 드러난 뒤에는
되돌릴 수 없는 경우가 있습니다. **턴 종료 전에 모든 행동을 무조건 취소할 수 있는 것은 아닙니다.**

화면이 표시하는 되돌리기 가능 여부와 확인 버튼을 기준으로 진행하세요.

## 저장과 이어 하기

| 실행 방식 | 자동 저장 |
| --- | --- |
| 런처의 로컬·원격 모드 | 기본으로 켜짐; 설정에서 확인 |
| 터미널의 원격 서버 | 기본으로 켜짐; 끄는 옵션을 사용했다면 제외 |
| 터미널의 로컬 서버 | `--autosave`를 붙여야 켜짐 |

자동 저장은 턴이 넘어갈 때 갱신됩니다. 중단하기 전에는 로컬 화면의 **저장** 또는
호스트 패널의 **지금 저장**도 사용하세요. 서버 창을 닫기 전에 저장해야 진행 중인 선택을 잃을 가능성을 줄일 수 있습니다.

기본 저장 위치는 **서버 PC의 프로젝트 폴더 안 `saves/`**입니다.
참가자의 브라우저가 게임 저장 파일을 보관하는 방식이 아닙니다.

서버를 다시 켜고 저장 목록에서 게임을 불러옵니다. 원격 게임을 불러오면 방 링크가 바뀌므로
호스트가 새 링크를 보내고 참가자는 그 방의 원래 좌석에 다시 참여합니다.

## 업데이트 전에

진행 중인 판은 사용하던 코드와 모델로 마친 뒤 업데이트하는 편이 좋습니다.
규칙·행동 버전이 바뀌면 이전 저장을 현재 서버에서 바로 열지 못할 수 있습니다.

프로젝트 폴더를 옮기거나 정리할 때는 저장 폴더와 사용하던 모델 파일을 함께 보존하세요.
학습 모델을 새 파일로 교체해도 예전 파일을 바로 지우지 마세요. 기존 저장이 그 모델 파일을 필요로 할 수 있습니다.

이전 판을 현재 엔진의 기보로 옮기는 도구는 있지만, 예전 게임을 현재 서버에서 언제나 그대로 이어 주는 기능을 뜻하지는 않습니다.
이전이 필요하면 [기보 안내](https://github.com/jungcheolseung/Dune-Imperium/blob/e7e9ad4f/docs/human-records.md)를 확인하세요.
