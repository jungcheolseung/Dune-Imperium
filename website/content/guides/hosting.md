호스트는 서버를 설치하고 켜 두며, 방과 저장을 관리하는 사람입니다.
참가자는 호스트가 보내는 링크로 들어옵니다. 호스트 자신도 게임방에서 사람 좌석에 참여해야 합니다.

먼저 [처음 한 판]({{< relref "guides/first-game.md" >}})에 따라 프로젝트와 런처를 준비하세요.
이 안내는 같은 네트워크 또는 Tailscale로 연결하는 비공개 모임을 기준으로 합니다.

## 1. 접속 경로 고르기

| 친구들의 위치 | 연결 방법 |
| --- | --- |
| 같은 Wi-Fi·유선 네트워크 | 호스트 PC의 LAN 주소 사용 |
| 서로 다른 장소 | Tailscale 설치·로그인 후 서버 PC를 참가자에게 공유 |

같은 장소에서는 기기끼리 연결을 막는 게스트 Wi-Fi를 피하세요.
다른 장소라면 [Tailscale 공식 머신 공유 안내](https://tailscale.com/docs/features/sharing)에 따라
서버 PC의 공유 초대를 만들고 참가자가 수락하게 합니다.

## 2. 원격 서버 켜기

1. **Dune Imperium Server** 런처를 엽니다.
2. **다른 사람과 (원격)**을 고릅니다.
3. 주소 목록에서 같은 장소면 LAN, 다른 장소면 Tailscale 주소를 선택합니다.
4. **시작**을 누르고 브라우저에 열린 관리자 화면에서 기본 판과 확장, 좌석을 골라 게임을 만듭니다.

사람 좌석 수에는 호스트 자신을 포함합니다. 나머지는 AI로 채울 수 있습니다.
별도 모델이 없는 환경에서는 앱 AI를 사용하세요. 원판 게임에는 앱 AI·휴리스틱·랜덤 AI만 앉습니다.

WSL에서 런처를 쓰면 원격 모드의 서버는 모든 주소에서 연결을 받고, 관리자 링크는 Windows에서 `127.0.0.1`로 열립니다.
친구에게 보내는 방 링크는 고른 주소 그대로입니다. LAN 주소가 친구에게 열리지 않으면 Windows 방화벽이 막는 것이니
Tailscale 주소를 쓰세요.

터미널을 쓰려면 실제 호스트 PC의 주소로 실행합니다. 아래 주소는 예시이므로 두 곳 모두 바꿔야 합니다.

```bash
uv run dune-imperium-server --remote --host 192.168.1.20 --public-url http://192.168.1.20:8000
```

이 구성의 호스트도 지정한 LAN 주소로 접속합니다. 원격 서버는 기본으로 턴 전환 때 자동 저장합니다.

터미널에서 관리자 키를 직접 정할 때(`--admin-key` 또는 `DUNE_IMPERIUM_ADMIN_KEY`)는 영문자·숫자·`-`·`_`로
**16자 이상**이어야 합니다. 짧거나 다른 문자가 섞이면 서버가 이유를 알리고 시작하지 않습니다. 키를 정하지 않으면
서버가 시작할 때마다 새 키를 만듭니다. 런처는 이 규칙에 맞는 키를 알아서 만듭니다.

## 3. 방 링크 보내기

생성한 게임을 선택해 **방 링크 복사**를 누르고 친구들에게 보냅니다.
`/#game=...`까지 포함한 링크 전체와 [참가자 안내]({{< relref "guides/joining.md" >}})를 함께 전달하세요.

관리자 링크는 방을 관리하는 링크이므로 호스트가 보관합니다. 참가자에게는 게임방 링크를 보냅니다.
Tailscale로 처음 연결하는 친구에게는 머신 공유 초대 링크도 별도로 필요합니다.

사람 좌석이 있는 방은 **게임 대기실**로 열립니다. 참가자는 이름을 넣고 **참여**만 누르며, 사람 좌석이 모두 찰 때까지
게임은 진행되지 않습니다. 모두 모이면 참여한 사람 누구나 **게임 시작 ▶**을 누르고, 그때 서버가 사람들의 자리를
무작위로 정합니다.

## 4. 게임 중과 중단할 때

서버 PC와 런처를 켜 두세요. 참가자 한 명의 브라우저가 닫혀도 서버가 유지되면 방은 계속 존재합니다.
다시 참여할 때는 처음 사용한 브라우저와 같은 방 링크를 쓰게 안내하세요.

중단하기 전 호스트 패널의 **지금 저장**을 누릅니다. 서버를 다시 켜고 저장을 불러오면 새 방 링크가 생기므로
그 링크를 다시 보내고 원래 좌석에 참여하게 합니다.

## 업데이트한 뒤

2026년 11월 3일 서버 보안 보강 뒤로는 관리자 브라우저가 키 자체가 아니라 키로 서명한 세션을 쿠키로 받습니다.
그 전 버전에서 쓰던 브라우저는 업데이트 뒤 **관리자 링크를 한 번 다시 열어야** 호스트 자격을 되찾습니다.
같은 키로 다시 띄운 서버에서는 그 뒤 30일 동안 그대로 호스트이고, 키를 바꾸면 관리자 링크를 다시 엽니다.
관리자 링크가 1분에 다섯 번 넘게 틀리면 잠시 거절되니 1분 뒤 맞는 링크로 다시 엽니다.

Windows 방화벽·주소 선택·좌석 해제·복구의 상세 절차는
[호스트 상세 가이드](https://github.com/jungcheolseung/Dune-Imperium/blob/master/docs/remote-play-host-guide.md)를 참고하세요.
Windows 11 네이티브와 WSL 호스트의 서버 실행은 확인했지만, 다른 PC에서 Windows·WSL 호스트로 접속하는 경우는 아직 확인하지 않았습니다.
