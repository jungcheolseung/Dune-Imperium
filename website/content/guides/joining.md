친구가 이미 방을 만들었다면 게임 소스나 Python을 설치하지 않아도 됩니다.
PC의 최신 브라우저와 호스트가 보내 준 **방 링크 전체**를 준비하세요. 쿠키를 허용해야 합니다.

## 같은 Wi-Fi·유선 네트워크라면

1. 호스트와 같은 일반 네트워크에 연결합니다.
2. 받은 방 링크를 브라우저에서 엽니다. `/#game=...` 부분까지 포함해야 합니다.
3. 이름을 입력하고 사용할 빈 사람 좌석의 **참여**를 누릅니다.

그림과 AI는 호스트가 준비합니다. 내 PC에 카드 파일이나 모델 파일을 복사할 필요는 없습니다.

## 서로 다른 장소라면

현재 안내하는 연결 방식은 Tailscale입니다.

1. [Tailscale](https://tailscale.com/download)을 설치하고 내 계정으로 로그인합니다.
2. 호스트에게 받은 **머신 공유 초대**를 수락합니다.
3. Tailscale 목록에서 호스트 PC가 보이는지 확인합니다.
4. 호스트에게 받은 **게임방 링크**를 열고 이름과 좌석을 선택합니다.

머신 공유 초대는 호스트 PC에 연결하도록 허용하고, 게임방 링크는 실제 게임에 들어가게 합니다.
두 링크는 서로 다릅니다. 초대가 수락되지 않으면 호스트에게 알려 주세요.
[Tailscale 공유 안내](https://tailscale.com/docs/features/sharing)

공유받은 PC가 다른 주소로 보이면 Tailscale 목록의 호스트 주소와 방 링크를 비교하세요.
주소를 고칠 때는 호스트와 확인하고 주소 부분만 바꾸며, 포트와 `/#game=...`은 유지합니다.

## 새로고침하거나 다시 들어올 때

**같은 방 링크와 같은 브라우저·프로필**을 사용하세요. 좌석은 이름만이 아니라 브라우저의 쿠키와 연결됩니다.
시크릿 창이나 다른 브라우저는 새 접속으로 취급될 수 있습니다.

쿠키를 지웠거나 기기를 바꿨다면 호스트에게 기존 참여를 해제해 달라고 요청한 뒤 다시 참여하세요.
기존 브라우저를 쓸 수 있다면 **플레이어 → 참여 종료**를 하고 옮길 수도 있습니다.

## 연결이 끊겼다면

| 화면이나 증상 | 할 일 |
| --- | --- |
| 방 링크가 열리지 않음 | 네트워크·Tailscale 연결과 호스트 서버 실행 여부 확인 |
| 서버 연결 끊김 | 내 연결을 복구하고 같은 링크로 새로고침; 계속되면 호스트에게 확인 |
| 내 좌석이 이미 사용 중 | 처음 브라우저·프로필 사용, 필요하면 호스트에게 참여 해제 요청 |
| 새 방 링크로 들어오라는 안내 | 호스트에게 복구한 게임의 새 링크를 받아 접속 |

게임 화면의 기본 흐름은 [기본 조작]({{< relref "guides/controls.md" >}})에서,
다른 문제는 [도움말]({{< relref "help/_index.md" >}})에서 볼 수 있습니다.
