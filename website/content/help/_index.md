## 이 웹사이트에서 게임을 바로 실행하나요?

게임 서버는 본인 또는 호스트의 PC에서 실행합니다. 사이트는 소개와 설치·사용 안내를 제공합니다.
[처음 한 판]({{< relref "guides/first-game.md" >}}) 또는 [친구 방 참여]({{< relref "guides/joining.md" >}})에서 시작하세요.

## 혼자 하려면 공식 솔로 규칙을 사용하나요?

이 프로젝트의 기본 대상은 4인 게임입니다. 혼자 시작하면 사람 한 명과 AI 세 명으로 구성합니다.
공식 Rivals 솔로 모드를 구현한 것은 아닙니다.

## 친구 방에 들어가는데 무엇을 설치하나요?

게임 소스와 Python은 호스트만 준비합니다. 같은 네트워크라면 참가자는 PC 브라우저로 방 링크를 엽니다.
다른 장소에서 연결할 때는 Tailscale 설치와 머신 공유 초대 수락도 필요합니다.

## 카드나 보드 그림이 보이지 않습니다

원본 이미지가 소스에 포함되지 않아서 생길 수 있습니다. 그림이 없어도 텍스트 화면으로 진행할 수 있습니다.
원격 참가자라면 이미지 준비 여부를 호스트에게 확인하세요.

## 탐색 AI가 목록에 없습니다

호스트가 호환 모델 파일과 추가 의존성을 준비했는지 확인하세요. 추가 패키지만 설치해도 모델이 자동으로 생기지는 않습니다.
모델은 지금 엔진의 행동 버전에 맞게 학습한 것이어야 하며, 버전이 다른 모델은 목록에 나와도 기대만큼 강하지 않습니다.
우선 별도 모델이 필요 없는 앱 AI로 시작할 수 있습니다. [AI 고르기]({{< relref "guides/choosing-ai.md" >}})

## 런처가 열리지 않거나 서버 시작에 실패합니다

프로젝트 폴더를 준비했는지, `uv --version`이 실행되는지 확인하세요. 런처의 오류 문구를 읽고,
터미널에서 진단하려면 프로젝트 폴더에서 다음을 실행합니다.

```bash
uv run python -m dune_imperium.launcher.cli --check
```

포트를 이미 사용하는 서버가 있다면 해당 서버를 확인하세요. Windows·Linux의 확인 범위는
[지원 현황]({{< relref "about/support.md" >}})을 참고하세요.

## 방 링크가 열리지 않습니다

- 호스트가 서버를 켜 두었는지 확인합니다.
- 같은 일반 Wi-Fi·유선망에 연결했는지, 다른 장소라면 Tailscale이 연결됐는지 확인합니다.
- `/#game=...`까지 포함한 방 링크 전체를 사용합니다.
- Tailscale로 공유받았다면 참가자 목록에 보이는 호스트 주소와 링크의 주소가 같은지 확인합니다.

주소가 다르거나 접속이 계속 실패하면 [참가자 안내]({{< relref "guides/joining.md" >}})와
[호스트 안내]({{< relref "guides/hosting.md" >}})를 함께 확인하세요.

## 새로고침하니 내 좌석이 이미 사용 중이라고 나옵니다

처음 들어갔던 브라우저·프로필과 방 주소를 그대로 사용하세요. 같은 이름을 입력하는 것만으로 자리를 되찾지는 못합니다.
쿠키를 지웠거나 기기를 바꿨다면 호스트에게 기존 참여를 해제해 달라고 요청한 뒤 다시 참여합니다.

## 선택을 마쳤는데 차례가 넘어가지 않습니다

화면에 **턴 종료 ▶** 또는 **확정 ▶**가 남았는지 확인하세요. 버튼을 눌러야 선택이나 차례가 확정되는 경우가 있습니다.
되돌릴 수 있는 행동도 화면의 되돌리기 표시로 확인합니다. [기본 조작]({{< relref "guides/controls.md" >}})

## 저장은 어디에 있나요? 업데이트 뒤에 열리지 않으면요?

기본 저장 위치는 서버 PC의 프로젝트 폴더 안 `saves/`입니다. 업데이트로 규칙·행동 버전이 바뀌면 이전 저장을
서버에서 바로 불러오지 못할 수 있습니다. 진행 중인 판은 같은 코드와 모델로 마치는 편이 좋습니다.
원본 저장을 보존하고, 기보 이전이 필요하면
[저장소의 기보 안내](https://github.com/jungcheolseung/Dune-Imperium/blob/master/docs/human-records.md)를 확인하세요.
기보 이전과 예전 저장을 현재 서버에서 그대로 이어 하는 것은 같은 기능이 아닙니다.

## 버그나 제안은 어디에 남기나요?

[GitHub Issues](https://github.com/jungcheolseung/Dune-Imperium/issues)에 다음을 함께 적어 주세요.

- 운영체제와 브라우저, 사용한 코드 버전.
- 켠 확장·모듈, 어떤 조작 뒤에 문제가 났는지.
- 기대한 동작, 실제 동작, 화면에 나온 오류 문구.

저장·로그를 첨부할 때는 관리자 링크·키와 참여자 정보가 없는지 확인하세요. 방 접속 문제라면
같은 네트워크인지, Tailscale을 사용하는지도 알려 주세요.
