AI가 자기와 비슷한 상대하고만 두면 무엇을 배울까요?
다른 방식으로 두는 상대를 학습에 섞으면 실제 대전에서도 나아질까요?

2026년 10월 7일에는 같은 모델에서 출발해 학습 상대만 다르게 구성한 두 실험을 비교했습니다.
이 글은 **당시 첫 1,000회 학습 연장의 결과**를 소개합니다. 현재 플레이용 모델의 성능을 측정한 글은 아닙니다.

## 비교한 두 모델

출발점은 같은 학습 모델 `8081`입니다. 룰셋과 학습 설정, 사용하는 게임 seed의 순서는 맞추고 상대 구성을 바꿨습니다.

| 구성 | 한 번의 학습 수집에 쓰는 32판 |
| --- | --- |
| M: 앱 AI 상대를 섞기 | 16판은 학습 모델 두 좌석과 앱 AI 어려움 두 좌석, 나머지 16판은 self-play |
| S: self-play만 하기 | 32판 모두 학습 모델끼리 플레이 |

두 모델을 각각 1,000회 더 학습했습니다. 앱 AI의 행동은 학습 모델의 데이터가 아니므로,
한 회에 수집되는 학습 좌석 수는 M이 96좌석-판, S가 128좌석-판입니다.
같은 학습 횟수의 비교이며 데이터 양이나 실행 시간을 같게 만든 실험은 아닙니다.

## 실험 조건

- 측정일: 2026년 10월 7일.
- 엔진 코드: `381f2e42`, 행동 codec v138, 관측 v30.
- 룰셋: CHOAM·프로모·Bloodlines·Tech·Immortality·Go to 11·Epic·Arrakeen Scouts와 지도자 드래프트 사용.
- 학습률: `1e-4`, 미니배치 1,024, 수집 작업 프로세스 네 개.
- 평가: 학습과 학습 중 평가에 사용하지 않은 별도 seed 사용. 평가 시작 seed는 3,400,000.

학습 중에 짧게 재는 승률은 진행 상태를 보는 신호로 사용했습니다.
최종 판단은 별도의 대전에서 하고 승률 외에 평균 순위와 점수 차도 확인했습니다.

## 모델끼리 두면 섞은 쪽이 앞섰습니다

M 두 좌석과 S 두 좌석을 넣어 2,800판을 비교했습니다.
팀전이 아니라 네 좌석이 각자 우승을 노리는 게임이며, 아래는 각 모델의 두 좌석이 차지한 승리 몫을 합친 값입니다.

| 결과 | M | S |
| --- | ---: | ---: |
| 승리 몫 | 52.9% | 47.1% |

원자료의 반올림 전 값으로 계산한 차이는 **+5.9%p**, 95% 구간은 **[+2.2, +9.5]%p**였습니다.
평균 순위와 승점 마진도 M 쪽이 나았습니다. 이 조건에서는 다른 상대를 섞은 모델이 직접 대결에서 앞섰습니다.

다만 이 결과만으로 모든 게임이나 학습 단계에서 같은 구성이 좋다고 일반화할 수는 없습니다.
비교한 시작 모델, 규칙, 상대와 학습 길이 안에서 얻은 결과입니다.

## 탐색에 넣으면 결과가 달랐습니다

실제 플레이에서는 모델을 바로 쓰기도 하지만, 모델을 후보 선택과 미래 평가에 사용하는 탐색 AI로도 씁니다.
그래서 새 모델 M과 출발 모델 8081을 각각 탐색에 넣어 앱 AI 어려움 세 좌석을 상대하게 했습니다.

같은 seed를 사용한 200판씩의 비교 결과는 다음과 같습니다.

| 탐색 AI에 넣은 모델 | 앱 AI 어려움 세 좌석 상대 승률 |
| --- | ---: |
| 출발 모델 8081 | 79.5% |
| 새 모델 M | 69.0% |

M을 사용한 탐색의 차이는 **−10.5%p**, 95% 구간은 **[−17.5, −3.5]%p**였습니다.
모델이 직접 수를 고르는 대전의 개선이 탐색에서도 그대로 나타나지는 않았습니다.

탐색은 정책으로 후보를 고르고 가치로 미래 국면을 평가합니다.
그래서 다른 상대에게 강해진 정책과 탐색 안에서 유용한 가치 판단이 같은 방향으로 바뀐다고 보장할 수는 없습니다.
이는 가능한 설명이며 이 비교만으로 원인을 확정한 것은 아닙니다.

## 이 실험에서 배운 것

학습 결과를 사용할 방식으로 평가해야 합니다. 모델이 직접 고른 수로 이기는지와,
그 모델을 탐색에 넣었을 때 이기는지를 따로 확인해야 했습니다.
당시 첫 비교에서는 모델 학습 계보와 플레이 서버의 탐색 모델을 구분해 관리했습니다.

이후 새 seed에서의 확인과 추가 연장 실험도 이어졌습니다.
그 결과까지 포함한 [전체 실험 기록](https://github.com/jungcheolseung/Dune-Imperium/blob/e7e9ad4f/docs/evaluation/m10-2026-10-07.md)을
함께 볼 수 있습니다. 이 글의 수치는 그 기록의 1~4절에서 가져왔으며, 후속 실험이나 현재 모델의 수치와 합쳐 쓰지 않았습니다.

탐색이 정책·가치를 사용하는 방식은 [AI가 한 수를 고르는 과정]({{< relref "posts/how-search-ai-chooses.md" >}})에서 설명합니다.
